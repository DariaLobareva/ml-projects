## 1. Альфа-Будущее 2026: скоринговая модель для кредитного конвейера

**Хакатон Альфа-Банка** · кейс «Умный кредитный кабинет предпринимателя»  
**Роль:** ML-инженер · **Статус:** ожидается финал

### Задача

Команда разрабатывала прототип цифрового кредитного конвейера для малого и микробизнеса: от подачи заявки клиентом до решения банка.
Я отвечала за скоринговую модель вероятности дефолта (PD) и логику кредитного решения:

данные клиента и заявки → проверки → оценка PD → зона риска → решение

### Качество модели

Проверка на отложенной выборке за последние 6 месяцев.

| Метрика | Значение | Вывод |
|---|---|---|
| Gini (обучение / проверка) | 0,61 / 0,60 | переобучения нет |
| KS | 0,47 (критическое значение 0,06) | модель хорошо разделяет надёжных и проблемных заёмщиков |
| Тест Хосмера–Лемешоу | 12,3 (порог 15,51) | прогноз PD согласуется с фактической долей дефолтов |
| PSI | 0,004 | модель стабильна во времени |
| Gini по продуктам | 0,59–0,62 | качество одинаково для кредита, овердрафта и кредитной линии |

### Зоны риска

| Зона | Доля заявок | Доля дефолтов |
|---|---|---|
| Зелёная | 78% | 4,6% |
| Жёлтая | 12% | 19,6% |
| Красная | 10% | 37,9% |

Доля дефолтов в красной зоне в 8 раз выше, чем в зелёной. Это позволяет автоматически обрабатывать большинство заявок и направлять на ручную проверку только рискованные.

**Стек:** Python, pandas, scikit-learn

## 2. Извлечение атрибутов товаров из поисковых запросов

**NLP · маркетплейс · учебный проект**

### Задача

По поисковым запросам пользователей маркетплейса автоматически определять атрибуты товара: бренд, цвет, пол, размер, категорию и совместимость.

### Что сделано

- **EDA** на 20 000 обезличенных запросов: частотный анализ n-грамм, эмбеддинги SentenceTransformer, кластеризация KMeans, визуализация UMAP.
- **Извлечение атрибутов** через лемматизацию (pymorphy3) и правила на регулярных выражениях.
- **Валидация** на размеченной выборке по precision, recall и F1.

**Стек:** Python, pandas, sentence-transformers, scikit-learn, UMAP, pymorphy3, regex
